ChildCareTimeline — pacote de upgrade

Conteúdo:
- Backup JSON: exportação e importação com validação e mesclagem sem apagar registros atuais.
- Ícones PNG de 192x192 e 512x512, mantendo o SVG.
- Manifesto atualizado.
- Service Worker com cache v2, limpeza apenas dos caches antigos do ChildCareTimeline e navegação offline.

Instalação no cPanel:
1. Faça uma cópia de segurança da pasta atual do site.
2. Extraia este ZIP no computador.
3. Envie/substitua os arquivos e a pasta icons no Document Root do subdomínio.
4. Não envie a pasta .git para a pasta pública do site.
5. Abra o site, atualize com Ctrl+F5 e teste exportação/importação com dados de teste.

Atenção: este pacote não foi publicado no GitHub nem enviado ao servidor.
